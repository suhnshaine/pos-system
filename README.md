## Installation

### Clone the Repository

```bash
git clone https://github.com/suhnshaine/pos-system.git
```

### Navigate to the Project Folder

```bash
cd pos-system
```

3. Ensure Apache and MySQL are running in XAMPP.

## Running the Application

Start the development server:

```bash
php spark serve
```

Open:

```text
http://localhost:8080
```
